# MG 短剧视频插件

本仓库用于发布 MG 短剧视频插件的正式安装包与在线更新清单。

请到 [Releases](https://github.com/huangweif522-star/plugins/releases/latest) 下载最新版。旧版用户首次使用在线更新前，需手动安装 v2.3.0 或更高版本。

安装后，插件底部的“检查插件更新”会读取最新正式发行版附件 latest.json。发现新版本并确认下载后，等任务完成，退出所有字字动画窗口并重新打开，插件将在下次加载时安装更新。

## 发布维护

release-assets 目录保存待发布附件。ZIP 以 Base64 文本存放，发布流程会解码、校验 SHA-256 并将 ZIP 与 latest.json 上传至对应版本的正式发行版。此目录仅存放经检查的通用发布文件。

修改对应版本的 latest.json 会触发发布。每版使用独立标签，已发布的版本应保持原样。
